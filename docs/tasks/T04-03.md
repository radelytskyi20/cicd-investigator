# T04-03 Build investigation and report history UI

Stage 4 | Status: Ready for review | Depends on: [T04-02](T04-02.md)

## Approved reduced scope

Connect the single screen to the existing SignalR hub without automatic reconnect. Show actual tool activity, compact validated reports, evidence links, a follow-up field, Stop, explicit Save and independent saved-report history. Fresh investigation replaces the SDK context. Selecting another run disconnects the current session; tab closure is handled server-side. No localStorage, conversation restore or full chat transcript UI.

Report revisions, elaborate navigation, fake progress and a design system are deferred. Browser calls the API, never AI directly. Pin the installed SignalR JavaScript client version.

## Completion record

- Implemented: real SignalR transport, activity, report/evidence rendering, follow-up, Stop, Save and history.
- Checks: production build passed. Real browser S01 report took 26.7 seconds / 8 tool calls; the cache follow-up took 8.3 seconds / 0 new tool calls. Both saved successfully as independent reports. Stop returned Stopped; closing a fresh active investigation cancelled it and disposed the owned CLI process.
- Limitations: single client; no automatic retry/reconnect; model output may require an explicit corrective follow-up if validation fails.
- Owner acceptance: Pending. See [Stage 4 review](../stage-4-review.md).
