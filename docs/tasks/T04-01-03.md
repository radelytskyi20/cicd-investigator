# T04-01-03 Save and reopen a validated completed report

Stage 4 | Status: Ready for review | Blocked by: T04-01-01

## Approved delivery

Give each validated result a server-owned ID. Explicitly save the latest completed result from the idle active session to SQL. List and reopen independently saved reports. The MCP host remains the migration owner; report persistence is an API write, never an MCP tool.

## Acceptance

- Save accepts a result ID, not arbitrary client-authored report content.
- Repeated Save of the same ID returns the same saved report.
- Unknown/expired IDs and saves during active analysis are rejected.
- Write failures never report success; the result remains available for retry while the session survives.
- Persist only completed report content and metadata, never chat or drafts.
- Saved content survives restart and remains readable without restoring a conversation.
