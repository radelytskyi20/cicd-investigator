## Stack

C#; GitHub.Copilot.SDK; System.Text.Json; application DTOs and validators; domain query services; MCP tool events.

## Goal

Produce an evidence-based investigation result that can be checked and saved.

## Implementation

1. Define Investigator instructions: identify the run, localize failed jobs, select useful sources, compare baseline/changes, test hypotheses, account for conflicts and finish honestly. The model chooses checks rather than always calling every tool.
2. Allow only required CI/CD MCP tools. Exclude shell/write tools and unrelated servers through supported SDK configuration. Source content cannot change instructions or permissions.
3. Define a compact Report DTO: run/baseline, analytical outcome, cause category, qualitative confidence and reason, evidence, supporting/opposing hypotheses, limitations and recommendations. Use English for generated explanations and reports as well as repository documentation.
4. Collect evidence from actual returned MCP data with run/job/attempt/version/locator. Validate generated references against those results. If SDK events omit required payloads, use a thin SDK tool-to-MCP client bridge that records results; do not replace agent MCP reads with SQL.
5. Invalid JSON, nonexistent references or wrong source ownership must not become a ready-to-save report. Show an error and allow a user retry without an automatic endless repair loop.
6. Measure duration and tool-call count. Show actions and observations rather than hidden reasoning.

## Acceptance and checks

- S01 connects the observed test failure to a relevant available change and provides valid evidence and a verification recommendation.
- Insufficient data allows an unknown-cause result without invented diffs or successful skipped tests.
- Validation rejects false references and mixed attempts. The client receives a checked answerReady or an explicit error.
- Different inputs lead to meaningful differences in checks, with real MCP calls confirmed by events.

## Exclusions

No second LLM loop, automatic fixes, percentage confidence, long-term knowledge or database report storage in this task.
