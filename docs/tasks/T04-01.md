- [T04-01-04](T04-01-04.md): focused real persistence verification.

## Implementation and acceptance

ASP.NET Core REST reuses InvestigationQueries. One SavedReports table stores completed report JSON and minimal metadata. MCP startup applies its migration; MCP tools remain read-only. Save is serialized with agent turns and accepts only the latest completed result in the idle active session. Saved results are immutable; every separately saved follow-up is independent. Errors never claim a successful write. Dataset mismatch returns unavailable rather than replacement evidence.
