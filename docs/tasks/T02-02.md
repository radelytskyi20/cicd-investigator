## Stack

C#; EF Core LINQ and AsNoTracking; SQL Server; System.Text.Json; xUnit.

## Goal

Provide small query services reusable by MCP tools and the future user-facing API.

## Implementation

1. Implement filtered run listing, run/job details, log ranges or search, test results by job/attempt, commits and available diff, and baseline candidates.
2. Choose the preceding completed successful run in the same pipeline/ref. Return available comparability context, including SDK, configuration and job differences.
3. Define DTOs that distinguish data, not found, unavailable, partial/truncated and invalid input. Missing test results must not imply success.
4. Attach dataset version, run, job, attempt and line range to log responses. Search reports the inspected scope. Bound the returned log fragment; this is a source-reading contract, not an agent-work budget.
5. Share baseline rules rather than duplicating them in API and MCP. Avoid a generic repository, CQRS or a separate mapping framework.

## Acceptance and checks

- S01 queries return the correct sources, baseline and diff without mixing jobs or attempts.
- Small focused tests cover no baseline, unknown run, a partial log and a noncomparable candidate; no extra demonstration incident matrix is required.
- DTOs expose neither evaluator diagnoses nor arbitrary SQL execution.

## Exclusions

No LLM, user-facing HTTP endpoints or CI/CD write operations.
