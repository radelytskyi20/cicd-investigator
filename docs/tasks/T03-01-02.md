# T03-01-02: Verify cancellation and fresh-session behavior

**Parent:** [T03-01](T03-01.md)
**Blocked by:** T03-01-01
**Status:** Planned
**Execution approval:** Approved by the owner on November 4, 2026.

## What to build

SDK work can be stopped, and a subsequent investigation starts in a fresh conversation using the same local login.

## Acceptance criteria

- [ ] Cancellation stops active generation and further MCP calls after cancellation processing.
- [ ] Normal SDK disposal releases the session and application-owned runtime resources.
- [ ] A new session does not resume the previous conversation.
- [ ] CLI-managed files are acceptable; custom storage isolation, transcript cleanup and global configuration changes are out of scope.
- [ ] Verification results and relevant limitations are documented.
